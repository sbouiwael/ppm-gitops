1. The frontend is deploying. Check rollout status:

   kubectl rollout status deployment/{{ include "ppm-frontend.fullname" . }} -n {{ .Release.Namespace }}

2. Get the application URL:

{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
   http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}/
{{- end }}
{{- else }}
   export POD=$(kubectl get pods -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "ppm-frontend.name" . }},app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath="{.items[0].metadata.name}")
   kubectl port-forward $POD 8080:80 -n {{ .Release.Namespace }}
   # Then visit: http://localhost:8080/
{{- end }}

3. Backend proxy:
   Nginx proxies /api/* requests to: {{ .Values.env.BACKEND_URL }}
   Ensure the backend Service is reachable at that address from within the cluster.

4. Autoscaling:
{{- if .Values.autoscaling.enabled }}
   HPA is ENABLED (min={{ .Values.autoscaling.minReplicas }}, max={{ .Values.autoscaling.maxReplicas }}).
   The frontend is stateless — scaling is safe.
{{- else }}
   HPA is disabled. Running {{ .Values.replicaCount }} replica(s).
   Enable in values-prod.yaml once the cluster has metrics-server installed.
{{- end }}
